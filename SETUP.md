# ⚡ SETUP RÁPIDO - 5 MINUTOS

## Opção 1: Replit (MAIS FÁCIL)

### Passo 1: Abra Replit
```
https://replit.com
```

### Passo 2: Novo Projeto
- Clique "+ Create"
- Selecione "Node.js"
- Nomeie "hyago-cognitivo"

### Passo 3: Copie os Arquivos
- Copie o conteúdo de cada arquivo deste projeto
- Cole em Replit (criar os mesmos nomes)

### Passo 4: Install & Run
```bash
npm install
npm run dev
```

### Passo 5: Abra a URL
- Replit vai dar uma URL (algo como https://replit.com/@seu-user/hyago...)
- Abra nela no navegador

### Passo 6: Use a Chave Groq
```
1. Abra https://console.groq.com
2. Faça Login/Signup
3. Vá em "API Keys"
4. Crie uma nova
5. Copie toda a string
6. Cole no campo do app
```

**PRONTO! Seu app está rodando! 🚀**

---

## Opção 2: Vercel (MAIS PROFISSIONAL)

### Passo 1: GitHub
1. Crie conta em https://github.com
2. Crie novo repositório (nome: hyago-cognitivo)
3. Faça upload dos arquivos

### Passo 2: Vercel
1. Vá em https://vercel.com
2. Faça login com GitHub
3. Clique "New Project"
4. Selecione seu repositório
5. Clique "Deploy"

### Passo 3: Sua URL Pública
- Vercel gera uma URL tipo: https://hyago-cognitivo.vercel.app
- Essa é sua URL permanente!

### Passo 4: Use a Chave Groq
```
1. Abra https://console.groq.com
2. Faça Login/Signup
3. Vá em "API Keys"
4. Crie uma nova
5. Copie toda a string
6. Cole no seu app rodando
```

**PRONTO! Seu app está online 24/7! 🌐**

---

## Onde Obter Chave Groq (3 minutos)

```
1. Abra: https://console.groq.com
2. Clique "Sign Up" (ou "Sign In")
3. Use Google/GitHub/Email
4. Confirme email (se necessário)
5. Vá em "API Keys" (menu esquerdo)
6. Clique "Create API Key"
7. Copie a string completa
8. Guarde em lugar seguro (não compartilhe!)
```

**A chave Groq é GRATUITA E ILIMITADA! ✅**

## Se Algo der Errado

**Erro: "Cannot find module"**
```bash
npm install
```

**Erro: "Port already in use"**
```bash
npm run dev -- --port 3001
```

**Erro: "Chave Groq inválida"**
```
Vá em https://console.groq.com
Gere uma nova chave
Copie corretamente
```

## Dúvidas?

- **Groq lento?** É rápido, espere 2-3 segundos
- **Chave expirou?** Não expira, valida no console.groq.com
- **Dados sumiram?** Estão no localStorage (cache do navegador)
- **App quebrou?** Recarregue (F5) e tente novamente
